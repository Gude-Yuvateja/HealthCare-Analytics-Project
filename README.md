# 📊 Healthcare Analytics Project
The Healthcare Analytics Project focuses on analyzing patient and hospital datasets to understand healthcare trends, diagnosis insights, and operational performance. The project includes data cleaning, transformation, analysis, and dashboard creation using SQL, Excel, and Power BI/Tableau.

# ⭐ Key Highlights
* Analyzed 10,000+ healthcare patient records to study patient visits, diagnosis conditions, and lab results.
* Performed data cleaning and transformation using SQL and Excel.
* Built interactive dashboards to monitor KPIs such as total patients, visits, follow-up rate, doctor workload, and revenue.
* Created visualizations including visit trends, state-wise patient distribution, age group analysis, and diagnosis insights.

# 🛠 Tools & Technologies
* SQL
* Microsoft Excel
* Power BI / Tableau

# 📈 Project Outcome
Developed analytical dashboards and reports to support healthcare data analysis, operational monitoring, and data-driven decision-making.
